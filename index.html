The strongest thread through Rupinder's work is applied visual intelligence: building deep learning and machine learning workflows that turn thermal video, RGB imagery, and multiview data into useful signals for real applications.

Recent work includes turmeric adulteration detection with thermal video analysis, machine learning using RGB and thermal imagery, and plant growth modeling with multiview images. Taken together, these projects point to a clear interest in visual intelligence for applied domains.
